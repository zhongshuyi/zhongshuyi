## 🚀 近期在做

### [此刻 · Diary](https://github.com/zhongshuyi/diary)

一个本地优先的日记应用：用对话式速记、富文本和图片记录日常，支持离线保存、备份，以及可选的自托管同步。

Android 客户端使用 **Flutter / Dart**，Windows 客户端使用 **Electron / React**。目前在持续打磨记录体验、动画性能和同步流程。

[查看项目](https://github.com/zhongshuyi/diary) · [安装包与发布记录](https://github.com/zhongshuyi/diary/releases)
